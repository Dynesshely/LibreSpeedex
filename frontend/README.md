# LibreSpeed frontend

This directory contains the LibreSpeed UI assets: a terminal / CRT styled
single page frontend.

## Deployment

For installation and deployment, follow the top-level [README.md](../README.md).
This directory is copied as a whole: `index.html` loads its assets from
`frontend/`, so the layout here is the layout that gets served.

## Configuration

The configuration files live at the top level rather than here, because the page
fetches them relative to itself:

- `../server-list.json` contains the default server list used by the UI.
- `../settings.json` overrides selected `speedtest_worker.js` settings.

## Styling

- `styling/colors.css` holds the palette as CSS custom properties. Change the
  four phosphor values there to reskin the whole screen.
- `styling/tailwind.css` is generated by `npm run css` from `tailwind.src.css`,
  and is committed so deployments never need Node.
- The remaining stylesheets are component CSS (gauges, buttons, dialogs, the CRT
  glass layer, the chart frame).

## Scripts

- `javascript/index.js` drives the UI from the speedtest events.
- `javascript/realtime-chart.js` draws the realtime throughput plot.
- `javascript/crt-background.js` draws the pixelated backdrop.

## Notes

- The frontend expects modern browser features and does not support old
  browsers.
- This directory does not contain the backend or results-sharing files.
